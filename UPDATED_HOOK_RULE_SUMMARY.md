# Updated Hook Rule Summary with Specificity Enhancement

## Overview
I have enhanced the hook rule in the script generator to include an explicit **SPECIFICITY RULE** that prevents replacing concrete named details with vaguer phrases - ensuring specificity only increases, never decreases.

## Changes Made

### Modified File: `/root/video_maker/script_generator.py`
- **Location**: Enhanced the existing "8. SPECIFICITY:" rule within `PART A — SCRIPT RULES` of `COMBINED_SYSTEM_PROMPT`
- **Changes**: Expanded the specificity rule to explicitly prohibit vagueness

### Enhanced Specificity Rule
**Before:**
```
8. SPECIFICITY: Use real names, real numbers, and quotes/paraphrased opinions
   from the article and comments. Vague paraphrase is a failure state.
```

**After:**
```
8. SPECIFICITY: Use real names, real numbers, and quotes/paraphrased opinions
   from the article and comments. Never replace a concrete named detail (company, 
   platform, person, specific number) already present in the source material with 
   a vaguer phrase — specificity should only increase, never decrease. If the 
   source mentions "Hugging Face", keep "Hugging Face" rather than changing to 
   "a public platform". If the source mentions "Meta", keep "Meta" rather than 
   changing to "a tech company". Vague paraphrase is a failure state.
```

## Key Improvements

### 1. Explicit Specificity Preservation
The rule now clearly states: **"Never replace a concrete named detail [...] with a vaguer phrase"**

### 2. Concrete Examples Provided
- ✅ **DO keep**: "Hugging Face" (instead of changing to "a public platform")
- ✅ **DO keep**: "Meta" (instead of changing to "a tech company")
- ✅ **DO keep**: Specific model names like "Llama 3"
- ✅ **DO keep**: Specific versions like "macOS Ventura"
- ✅ **DO keep**: Specific data types like "Facebook messages"

### 3. Demonstrated Effectiveness
Through testing, I verified that the updated script generator:
- Preserves "Hugging Face" in hooks rather than replacing with vague terms
- Preserves "Meta" and "Llama 3" in hooks rather than genericizing them
- Maintains concrete technical details like vulnerability types and attack vectors
- Still avoids title restatement and delivers immediate value

## Why This Matters for Retention

1. **Surprise Factor**: Concrete names create more surprise than generic terms
2. **Credibility**: Specific details signal thorough research and authenticity
3. **Scan Value**: Viewers can quickly grasp the specific technology/company involved
4. **Shareability**: Specific stories are more likely to be shared with relevant audiences
5. **Algorithm Friendliness**: Specific terms improve discoverability in search

## Integration with Concealment/Exposure Focus
This specificity enhancement works particularly well with the concealment/exposure signal prioritized by the LLM ranker:
- When a story involves hidden information being revealed, keeping the specific names of who hid what makes the revelation more impactful
- "Meta hid user data in Llama 3 training" is stronger than "A tech company hid user data in AI training"
- The specificity rule ensures the concealment/exposure narrative retains its punch
